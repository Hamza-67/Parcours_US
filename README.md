## Site structure

The published site is a dependency-free static website:

- `index.html` — primary portfolio page
- `styles.css` — responsive visual system
- `404.html` — custom fallback page
- existing technical figures and project reports — evidence assets retained from the previous version

Open `index.html` directly or serve the repository with any static HTTP server.

## Content principles

- no confidential industrial data;
- no unsupported school equivalencies or inflated claims;
- synthetic data is identified explicitly;
- measurable outcomes are separated from planned work;
- English-first copy for international admissions and recruiting.
